# Contributing

1. Search existing issues before opening a focused bug or feature request.
2. Never include customer URLs, private content, credentials or personal data.
3. Create a branch from `main` and keep each pull request to one change.
4. Run the PHP lint, PHPUnit and Plugin Check commands documented in the README.
5. Explain user-visible changes and update `readme.txt` when necessary.

By contributing, you agree that your work may be distributed under GPL-3.0-or-later.

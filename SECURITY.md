# Security policy

## Supported version

Security fixes are considered for the latest public release, currently 2.0.x.

## Reporting a vulnerability

Do not publish vulnerabilities, private URLs, draft content or credentials in a GitHub issue. Send a concise report through the [Opace contact page](https://opace.agency/contact/) and mark it for the Essential SEO Toolkit maintainers. Include the affected version, impact and reproducible steps without customer data.
